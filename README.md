# Project Theme

## Deploy a Simple Python Web Application on Linux

This repository simulates the operational tasks involved in deploying and maintaining a backend application.

The project is intentionally broken into small subproblems.

Each folder represents:

* a real operational problem
* the commands used to solve it
* Bash scripting opportunities
* Linux concepts involved

---

# Concept Map

```text
Deploy Python Web App
├── Create project structure
├── Transfer application code
├── Install dependencies
├── Configure environment
├── Start application
├── Verify running processes
├── Monitor logs
├── Manage permissions
├── Automate deployment
└── Backup application
```
